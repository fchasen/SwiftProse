# Marks

Plain, **strong**, *em*, `code`, ~~strike~~, and [a link](https://example.com).

Nested: ***strong em***, **strong with *em* inside**, *em with **strong** inside*.

Code excludes: `code with **stars** inside stays literal`.

Adjacent runs: **a**b**c** and *a*b*c* with no space between them.

Marks over punctuation: **"quoted"**, *(parenthesised)*, ~~a-b-c~~.

Marks at line boundaries: **start of the line** and end of the line **here**

A very long marked run: **this run of bold text is deliberately long enough that it spans more than one line fragment in a normal container width, so the layout has to carry the mark across the break and back again without losing it**.

Escaped stars: \*not em\* and \*\*not strong\*\*.

Underscores: _em with underscores_ and __strong with underscores__ and snake_case_word.
